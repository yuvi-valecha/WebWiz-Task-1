# Responsive JEE Quiz Application

A dynamic, interactive web application designed for students to practice JEE-style multiple-choice questions. Built with a focus on smooth user experience and real-time feedback.

## 🚀 Features

Dynamic Question Loading: Fetches questions and options from a centralized data structure.
State Persistence: Remembers user answers when navigating back to previous questions.
Real-time Validation: Immediate color feedback (Green/Red) upon clicking the 'Check' button.
Intelligent UI: The 'Next' button automatically transforms into a 'Finish' button on the final question.
Score Tracking: Calculates and displays the final score on a dedicated results screen.

## 🛠️ Tech Stack

HTML5: Semantic structure for quiz layouts.
Tailwind CSS: For a modern, responsive "Glassmorphism" UI.
JavaScript (ES6+): Core logic, DOM manipulation, and state management.
